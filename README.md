# NetCrew Client

Cliente de escritorio oficial y multiplataforma (**macOS, Windows y Linux**) para conectarse de forma sencilla a redes privadas VPN P2P Mesh gestionadas con **[NetCrew](https://netcrew.es)**.

## Descargas
Descarga la última versión para tu sistema operativo desde la sección **[Releases](https://github.com/fredeabal/fredeabal-netcrew-app-releases/releases/latest)**:

- **macOS (Apple Silicon e Intel):** `NetCrew.Client_<version>_universal.dmg`
- **Windows (64-bit):** `NetCrew.Client_<version>_x64-setup.exe` o `.msi`
- **Linux (Ubuntu/Debian):** `NetCrew.Client_<version>_amd64.deb`
- **Linux (Universal / Fedora):** `.AppImage` / `.rpm`

## Primer arranque en macOS
Si macOS muestra el aviso *"Apple no ha podido verificar que NetCrew Client no contenga software malicioso"* al abrir la app por primera vez:
1. Pulsa **Aceptar**.
2. Abre **Ajustes del Sistema → Privacidad y seguridad** (sección *Seguridad*, abajo del todo).
3. Pulsa **Abrir de todas formas** junto al aviso de **NetCrew Client**.

## Primer arranque en Windows
Si **Windows SmartScreen** muestra una advertencia al ejecutar el instalador, pulsa **Más información → Ejecutar de todas formas**.

## Cómo conectarse
1. Abre **NetCrew Client**.
2. Importa tu perfil `.yml` arrastrándolo a la ventana, pulsando **`+`** o usando **Menú → Importar desde enlace** (`/connect/...`).
3. Activa el interruptor del perfil para conectarte (el sistema solicitará permisos de administrador para crear la interfaz VPN).
